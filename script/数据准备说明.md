# HMD-AMP 训练数据下载与准备说明

本目录新增两个脚本，帮你一键获取并整理训练数据：

| 脚本 | 作用 |
| --- | --- |
| `download_training_data.py` | 从 Zenodo 官方仓库下载训练数据（断点续传 + MD5 校验 + 自动解压） |
| `prepare_training_data.py` | 把原始 fasta 整理成训练脚本直接可用的 `fasta + label.npy` |

---

## 一、训练数据到底要不要自己找？

**分两个任务看：**

### 任务 1：AMP / non-AMP 二分类 —— 不用自己找数据 ✅

论文官方已经在 Zenodo 公开了训练集，直接下载即可：

- **`training_data.zip`（约 200 KB）**，解压后是：
  - `AMPs_5985.fasta`：5985 条已知抗菌肽（阳性，标签 1）
  - `non_AMPs_5985.fasta`：5985 条非抗菌肽（阴性，标签 0）

数据出处（论文 Data availability 中引用）：
- 最新版：https://doi.org/10.5281/zenodo.15622525
- README 引用版：https://doi.org/10.5281/zenodo.15583284
  （两个记录里的 `training_data.zip` 完全相同，MD5 均为 `f523bce225fb50a469e551618fff56ac`）

### 任务 2：AMP 靶标预测（Gram+ / Gram- / Mammalian_Cell / Virus / Fungus / Cancer）—— 需要自己准备靶标活性标签 ⚠️

Zenodo 的 `training_data.zip` 里**只有 AMP / non-AMP 两类序列，没有“某条 AMP 对哪个靶标有活性”的标签**。
而 `target_extract_repr.py` 需要每个靶标一个二分类标签文件（1 = 对该靶标有活性，0 = 无活性）。

这部分标签需要你按序列从公开 AMP 数据库的活性注释中获取/整理。常用数据库：

| 数据库 | 网址 | 说明 |
| --- | --- | --- |
| APD3 | https://aps.unmc.edu/ | 抗菌肽数据库，标注抗 G+/G-/真菌/病毒/抗癌/哺乳动物细胞等活性 |
| DBAASP | https://dbaasp.org/ | 有详细靶标与 MIC 信息 |
| DRAMP | http://dramp.cpu-bioinfor.org/ | 国产 AMP 数据库，含活性注释 |
| dbAMP | https://awi.cuhk.edu.cn/dbAMP/ | 含活性与靶标信息 |
| LAMP | http://biotechlab.fudan.edu.cn/database/lamp/ | 多活性标注 |
| UniProt | https://www.uniprot.org/ | 用 antimicrobial/antiviral/antifungal/anticancer 等关键词查功能描述 |

**对应关系**（与论文 6 个靶标对齐）：
- `Gram+`：抗革兰氏阳性菌（如 *S. aureus*）
- `Gram-`：抗革兰氏阴性菌（如 *E. coli*、*P. aeruginosa*）
- `Mammalian_Cell`：对哺乳动物细胞有作用（溶血 / 细胞毒性）
- `Virus`：抗病毒
- `Fungus`：抗真菌（如 *Candida*）
- `Cancer`：抗癌 / 抗肿瘤

`prepare_training_data.py` 会：
1. 先尝试**自动从 fasta 头部描述的关键词**（如 antiviral、anticancer、gram-positive…）解析靶标；
2. 同时生成一份**标注模板** `target_annotation_template.csv`，你把每条 AMP 对各靶标填 `1/0`；
3. 用 `--annotation 你的.csv` 重新运行，即可生成 6 个靶标的训练文件。

## 二、快速开始

```bash
# 第 1 步：下载训练数据（只下必需的 training_data.zip，约 200 KB）
python script/download_training_data.py --out data

# 第 2 步：整理成训练输入（自动生成 fasta + label.npy）
python script/prepare_training_data.py --raw_dir data/raw --out_dir data/processed
```

下载脚本会自动：
- 从 Zenodo 下载 `training_data.zip` 并做 MD5 校验（损坏自动重下）；
- 解压出 `AMPs_5985.fasta` / `non_AMPs_5985.fasta` 到 `data/raw/`；
- 支持断点续传（网络中断直接重跑即可）。

也可以一步到位（下载后自动整理）：

```bash
python script/download_training_data.py --out data --prepare
```

### （可选）下载作者已训练好的模型权重

训练不需要权重，但**直接做预测**时需要。可顺手下载（来自 README 中的 Google Drive 链接）：

```bash
pip install gdown
python script/download_training_data.py --models
```

### （可选，非训练数据）下载论文宏基因组挖掘用的超大文件

`8mammalian.faa.gz`（3.3 GB）、`swineGutORFs.faa.gz`（9.3 GB）等是论文里用来做
“从哺乳动物宿主/肠道微生物基因组挖掘新 AMP”的**待预测 ORF**，不是训练数据。
只有复现挖掘流程才需要：

```bash
python script/download_training_data.py --extra
```

## 三、准备脚本产出的文件结构

```
data/
├── raw/                                # 下载的原始数据
│   ├── training_data.zip
│   ├── AMPs_5985.fasta
│   └── non_AMPs_5985.fasta
└── processed/                          # prepare 脚本产出，训练直接用
    ├── prepare_report.txt              # 数据统计报告
    ├── amp_task/                       # 任务1：AMP/non-AMP
    │   ├── amp_train.fasta
    │   └── amp_label.npy               # 1=AMP, 0=non-AMP
    └── target_tasks/                   # 任务2：6 个靶标
        ├── target_annotation_template.csv   # ★ 靶标标签模板，需你填写
        ├── Gram+/
        │   ├── Gram+_train.fasta
        │   ├── Gram+_label.npy
        │   └── README.txt              # 若标签不全，会在此说明怎么补
        ├── Gram-/
        ├── Mammalian_Cell/
        ├── Virus/
        ├── Fungus/
        └── Cancer/
```

标签 `.npy` 是与 fasta **顺序一一对应**的一维 0/1 整数数组（1=阳性，0=阴性）。

## 四、准备好数据后怎么训练

```bash
cd script

# ===== 任务 1：AMP / non-AMP =====
# (1) 微调 ESM-2 并抽取嵌入
python amp_extract_repr.py \
    --training_data ../data/processed/amp_task/amp_train.fasta \
    --training_label ../data/processed/amp_task/amp_label.npy \
    --ftmodel_save_path ../model/amp_ft \
    --emb_path ../emb/amp
# (2) 用嵌入训练 deep forest 分类器
python amp_train.py \
    --training_emb ../emb/amp \
    --clsmodel_save_path ../model/amp_clsmodel

# ===== 任务 2：某靶标（以 Gram+ 为例）=====
python target_extract_repr.py --target Gram+ \
    --data_path ../data/processed/target_tasks/Gram+/Gram+_train.fasta \
    --label_path ../data/processed/target_tasks/Gram+/Gram+_label.npy \
    --ftmodel_save_path ../model/target_ft \
    --emb_path ../emb/target
python target_train.py --target Gram+ \
    --emb_path ../emb/target \
    --clsmodel_save_path ../model/target_clsmodel
```

> 说明：
> - ESM-2 650M 预训练权重（约 2.5 GB）会在**首次运行时由 fair-esm 自动下载**，需要联网。
> - 微调脚本默认使用 2 张 GPU（`device_ids=[0,1]`）。单卡机器请把脚本里的
>   `device_ids=[0, 1]` 改为 `[0]`；纯 CPU 微调 650M 模型非常慢，不推荐。
> - `prepare_training_data.py` 会自动做序列清洗（去 `*`、大写化）、长度过滤
>   （默认 5–100 肽，与论文 sORF 一致）、去重和类别平衡，可用
>   `--strict / --min-len / --max-len / --neg-include-nonamp` 调整。

## 五、靶标标签怎么填（当务之急的具体做法）

1. 运行准备脚本后，打开 `data/processed/target_tasks/target_annotation_template.csv`，
   每行是一条 AMP，列为 `id, sequence, Gram+, Gram-, Mammalian_Cell, Virus, Fungus, Cancer`。
2. 用 APD3/DBAASP/DRAMP/dbAMP 等数据库，按序列（或 ID）查询该 AMP 的活性类型：
   - 对某靶标**有活性** → 该列填 `1`（或 yes/true）；
   - **明确无活性** → 填 `0`（或 no/false）；
   - 不确定 → 留空（脚本会把留空的 AMP 当作该靶标的阴性候选处理）。
3. 保存后重新运行：
   ```bash
   python script/prepare_training_data.py \
       --raw_dir data/raw --out_dir data/processed \
       --annotation 你填好的.csv
   ```
   脚本会为每个“阳/阴样本都非空”的靶标生成 `fasta + label.npy`；
   标签不足的靶标会在对应目录写一个 `README.txt` 提示还缺多少阳性。
4. **阴性样本默认只使用“没有该活性的 AMP”**（即同一批 AMP 内做二分类，这也是
   论文靶标任务的做法）；若你希望把 5985 条 non-AMP 也加入阴性，加
   `--neg-include-nonamp`。
